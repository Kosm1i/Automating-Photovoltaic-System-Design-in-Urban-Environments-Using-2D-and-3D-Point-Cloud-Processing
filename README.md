# Automating-Photovoltaic-System-Design-in-Urban-Environments-Using-2D-and-3D-Point-Cloud-Processing
Inteligentny system w środowisku MATLAB do automatyzacji projektowania instalacji fotowoltaicznych. Wykorzystuje dane LiDAR (Geoportal) do segmentacji dachów 3D, analizy zacienienia opartej na ray-tracingu oraz optymalizacji topologii paneli PV.
